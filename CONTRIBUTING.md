# Contributing

The intial version of the project was created by the human authors, but most of the code is now generated by coding agents under the human direction. We read every diff and then merge manually.

The contributions that help most should carry knowledge that AI agents do not have, for example a domain schema for a specific field or use case, an example diagram, a partial runner, or a bug report with the diagram that reproduces it.

Hand-written PRs are still welcome and go through the same review as the automated ones. No AI tool is required to contribute.
